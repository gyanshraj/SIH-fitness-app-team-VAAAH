# Android App (Starter Structure)

This folder is a starter structure for an Android fitness app.

## Suggested Beginner Stack
- **Language**: Kotlin
- **UI**: Jetpack Compose
- **Architecture**: MVVM
- **Networking**: Retrofit + Kotlinx Serialization
- **Local Storage**: Room

## Basic Structure
- `app/src/main/java/com/vaaah/fitness/` → app code (screens, viewmodels, data)
- `app/src/main/res/layout/` → XML layouts (if used)
- `app/src/main/AndroidManifest.xml` → Android app manifest
